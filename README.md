# Task 1: Basic Network Sniffer

This task implements a network sniffer using Python and Scapy on Kali Linux.
The tool captures live network packets and analyzes IP addresses, protocols,
ports, payload preview, and traffic statistics.

# Features
- Live packet capturing
- Source & destination IP detection
- TCP / UDP protocol analysis
- Port information
- Payload preview
- Real-time traffic statistics
- Top source IP identification

# Tools Used
- Kali Linux
- Python 3
- Scapy library

# How to Run
```bash
sudo python3 advanced_sniffer.py
